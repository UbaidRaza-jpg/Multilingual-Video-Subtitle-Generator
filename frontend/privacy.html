Privacy Policy

Last Updated: October 2026

1. Overview

Multilingual Video Subtitle Generator is architected with a privacy-by-design approach. We respect your personal data and maintain transparent data handling practices. This Privacy Policy details how uploaded media, transcription outputs, and operational parameters are processed.

2. Media Processing and Automated File Deletion

When you upload a video for transcription, translation, or subtitle hardcoding:

  • Your media file is temporarily saved into an isolated server directory strictly to perform speech recognition and subtitle burning.
  • Audio extracts and generated subtitle files (.srt) exist only for the duration required to complete the task.
  • Automated Purge: Uploaded media and output videos are automatically and permanently deleted from server disks within 15 minutes of task completion.
  • We never store, retain, index, or distribute user-uploaded video or audio assets.

3. Machine Learning Models and Training

We do NOT use your video files, audio streams, transcriptions, or translations to train, fine-tune, or evaluate machine learning models. Speech recognition runs via faster-whisper on dedicated execution pipelines.

4. Optional Notification Data

If you optionally provide an email address to receive completion notifications:

  • The email address is strictly used to dispatch a one-time transactional message regarding your task status.
  • It is never added to promotional mailing lists, marketing databases, or shared with third-party advertising networks.

5. Cookies and Tracking

This application does not employ tracking cookies, invasive analytics pixels, fingerprinting scripts, or cross-site tracking mechanisms.

6. Security Controls

We implement defensive security controls including strict rate limiting per endpoint, HTTP security headers (nosniff, frame-ancestors, CSP), directory traversal validation, HTML entity sanitization, and constant-time authentication for administrative interfaces.

7. Contact and Inquiries

For technical inquiries or questions regarding privacy practices, contact the maintainer via the project repository: GitHub Repository.
